# YUI（結）— Web招待状テンプレート v1.0

by IDATSUKA — https://idatsuka.com

結婚式の Web 招待状のための、1ファイル完結の HTML テンプレートです。
ビルドツール・フレームワーク・外部ライブラリは一切不要。`index.html` を編集して
アップロードし、その URL を LINE などで送るだけで公開できます。

ゲストはこのページを「LINE から、スマホで、一度だけ」開きます。
そのとき知りたいこと —— **誰の式か / いつか / どこか / 何を着ればいいか / どう返事をするか** ——
が上から順に並ぶように設計しました。スマホ（390px）での見えかたを基準に作っています。

**写真がまだ無くても大丈夫です。** `assets/` に画像を置かなかった場合は、
淡いグラデーション（白＝生成り／夜＝あたたかい暗色）がそのまま表紙になり、
画像切れのアイコンは出ません。先に文章を入れて公開し、あとから前撮り写真に
差し替える使い方ができます。

## 使い方

1. `index.html` をテキストエディタで開く
2. ファイル冒頭のコメントに従い、`EDIT:` と書かれた箇所をおふたりの内容に差し替える
3. `<style>` 内の `:root` の CSS 変数で配色を調整する
   （夜のテーマは `[data-theme="noir"]` ブロックで調整）
4. 出欠フォームの送信先を設定する（下の「出欠フォーム（RSVP）の設定」を参照）
5. 写真を `assets/` に置く（任意。置かなければグラデーションになります）
6. `index.html` と `assets/` をサーバー（GitHub Pages / Netlify / レンタルサーバー等）に
   アップロードし、その URL をゲストに送る

### 最初に差し替える6か所

| 場所 | 内容 |
| --- | --- |
| `<title>` / `description` / `og:` / `canonical` | おふたりの名前・日付・公開URL（LINE で送ったときの見出しになります） |
| HERO の `<h1 class="hero-latin">` と `<p class="hero-kanji">` | ローマ字のお名前と漢字のお名前 |
| HERO の `<p class="hero-date">` / `<p class="hero-week">` | 挙式日（`2027.◯.◯`）と曜日 |
| HERO の `data-when="2027-06-12T11:00+09:00"` | カウントダウンの日時（1か所だけ） |
| `<script>` の `var RSVP_TO = '◯◯◯◯@example.com';` | 出欠フォームの送信先メールアドレス |
| 会場の `<table class="venue-table">` と地図 | 会場名・住所・電話・最寄駅・地図 |

そのほか、ごあいさつ文・当日の流れ・ドレスコード・プロフィール・回答期限・
お問い合わせ先も、すべて `EDIT:` コメントの付いた場所にあります。

### テーマについて

- 右上のボタンで **白（blanc）/ 夜（noir）** を切り替えられます（選択はブラウザに保存されます）
- 最初から夜で表示したい場合は `<html lang="ja" data-theme="blanc">` を
  `<html lang="ja" data-theme="noir">` に変更してください
- 切替ボタンが不要な場合は `.theme-btn` の `<button>` を削除してください
- スマホのアドレスバーの色も一緒に変わります。配色を変えたときは、
  JavaScript の `var BAR = { blanc: '#fdfaf7', noir: '#1a1614' };` も同じ色に揃えてください

### カウントダウンの設定

HERO の1か所だけを書き換えます。

```html
<div class="countdown" id="countdown" data-when="2027-06-12T11:00+09:00" hidden>
```

- 形式は `年-月-日T時:分+09:00`。`+09:00` は日本時間という意味です
- 時差を書いておくことで、**海外にいるゲストのスマホでも正しい残り時間**が表示されます
  （時差を省略した場合は日本時間として扱います）
- 表示は「残り ◯日 ◯時間 ◯分」。静かなページなので、秒は数えず1分ごとに更新します
- 挙式日時を過ぎると、自動で「**ありがとうございました**」に変わります
  （この文言は JavaScript の `EDIT:` コメントの行で変更できます）
- `data-when` を消す、または読めない書き方にすると、ブロックごと静かに非表示になります
  （カウントダウンが不要なときは `<div class="countdown">` ごと削除してください）

### 出欠フォーム（RSVP）の設定

送信には **FormSubmit**（https://formsubmit.co ）を使います。登録もサーバーも不要です。

1. `<script>` の中の1行を、おふたりの受信用メールアドレスに書き換えます

   ```js
   var RSVP_TO = '◯◯◯◯@example.com';
   ```

2. 公開したページから、一度テスト送信します
3. FormSubmit から確認メールが届くので、その中のリンクを1回クリックします
4. 以降、ゲストの回答がそのメールアドレスに届きます

- 送信は画面を切り替えずに行われ、成功するとフォームと入れ替わりで**お礼の画面**が出ます
- 通信に失敗したときは、入力内容を入れた**メールの下書きリンク**が出るので、
  ゲストはメールで返信できます（返事が届かない、ということが起きません）
- 迷惑メール対策の空欄（ハニーポット）が入っています。触らないでください
- 項目は「ご出欠（必須）／お名前（必須）／ふりがな（必須）／ご連絡先（必須）／
  ご同伴者／アレルギー・苦手なもの／メッセージ」です。
  不要な項目は `<div class="field">` ごと削除できます

> **個人情報のあつかいについて（必ずお読みください）**
> このフォームには、ゲストの お名前・ふりがな・メールアドレス・同伴者・**食物アレルギー**・
> メッセージが届きます。食物アレルギーは特に慎重なあつかいが必要な情報です。
> - 送信先は、おふたり専用のメールアドレスをお使いください。そのアドレスや受信箱の画面を、
>   SNS・ブログなど公開の場に載せないでください
> - 回答を、ご本人の許可なく他のゲストや第三者に見せないでください
>   （席次や引出物の手配で会場に共有するときは、必要な範囲だけにしてください）
> - **挙式と手配がすべて済んだら、受信したメールと控え（表計算ファイル等）は削除してください**
> - このページ自体は、入力内容をブラウザにもサーバーにも保存しません

### 写真について

`assets/` に置くだけで表示されます（すべて任意）。

| ファイル | 使う場所 | 推奨サイズ |
| --- | --- | --- |
| `assets/hero.jpg` | 表紙 | 縦長 1600×2000 程度 |
| `assets/groom.jpg` | ふたりについて・新郎のカード | 4:5 |
| `assets/bride.jpg` | ふたりについて・新婦のカード | 4:5 |

- 置かなかった場合は、`:root` の `--hero1`〜`--hero3` のグラデーションが表示されます
- **写真は必ず、写っているご本人と撮影者（カメラマン）の許諾を得たものをお使いください。**
  前撮り写真は、スタジオとの契約で Web 掲載が制限されている場合があります。事前にご確認ください
- 招待状を検索結果に出したくない場合は、`<head>` の `noindex` の行のコメントを外してください

## 特徴

- 1ファイル完結（HTML / CSS / JS すべて込み、外部ライブラリ・外部画像ゼロ）
- 白（blanc）／夜（noir）の2テーマ切替、`localStorage` に保存・`theme-color` も同期・描画前に適用
- **カウントダウン**：属性1つで動作。時差を明示して読むので海外の端末でも正確。
  1分ごとに更新し、当日を過ぎたら御礼の言葉に変わり、属性が無ければ静かに消えます
- **出欠フォーム（RSVP）**：FormSubmit で送信 → その場でお礼の画面に切替。
  失敗時は入力内容入りの `mailto:` にフォールバック。ブラウザ標準の必須チェック、
  `inputmode` / `autocomplete` 指定、`<fieldset>` + `<legend>`、
  すべての入力に `<label>`、タップ領域は 48〜56px
- スマホ優先の設計（390px が基準）。下から出る「出欠のご返信へ」ボタン付き
- 当日の流れ（縦線のタイムライン）、会場案内、地図プレースホルダ、送迎バス、
  ドレスコードの色見本、プロフィールカード2枚
- 写真が無くてもグラデーションで成立します（画像切れのアイコンを出しません）
- 3ファミリーのフォント（Marcellus / Klee One / Zen Maru Gothic）、すべてフォールバック指定つき
- 紙の繊維テクスチャ（SVG 生成・`--grain` で強さ調整、0 で消せます）
- `prefers-reduced-motion` 対応（動きを抑える設定では演出を止めて、全要素をそのまま表示します）
- 本文コントラスト 4.5:1 以上を両テーマで確認済み／390px で横スクロールなし／コンソールエラーなし
- OGP / canonical / theme-color / SVG ファビコン内蔵、`noindex` の切替行つき
- 日本語コメント付きで、HTML に不慣れな方でも差し替えやすい構成

## セクション構成

| # | セクション | 内容 |
| --- | --- | --- |
| 1 | HERO | ふたりの名前（ローマ字・漢字）、挙式日、曜日、カウントダウン、表紙写真（無ければグラデーション） |
| 2 | ごあいさつ | 一通の手紙のような短い文章、日付、連名、印（一文字） |
| 3 | 日時 | 受付・挙式・披露宴の時刻と、時間の補足 |
| 4 | 当日の流れ | 受付 → 挙式 → 写真 → 披露宴 → お開き（縦の線と時刻。項目は増やせます） |
| 5 | 会場 | 会場名・住所・電話・最寄駅・駐車場・地図プレースホルダ・地図アプリリンク・送迎バス |
| 6 | ドレスコード | 一言と、色見本の丸3つ、補足 |
| 7 | ふたりについて | プロフィールカード2枚（写真枠つき）と、出会いの話 |
| 8 | 出欠のご返信 | 回答期限＋出欠フォーム（送信後はお礼の画面に切替） |
| 9 | お問い合わせ | 新郎・新婦の連絡先とメール |
| 10 | FOOTER | 名前、日付、お礼の一文 |

上のバーは「しるし＋テーマ切替」だけの静かな作りです。
スマホでは、表紙を過ぎると下に「出欠のご返信へ」のボタンが出ます
（返信フォームが画面に入ると自動で引っ込みます）。

## 掲載内容についてのお願い

- お名前・会場名・住所・電話番号・日付・金額は、すべて「◯◯」「△△」「2027.◯.◯」
  「¥◯,◯◯◯」などのプレースホルダーです。公開前に必ず実際の内容へ差し替えてください
- **実在しない会場名・店名を書かないでください。** 実在する会場を載せるときは、正式名称・住所・
  電話番号を正確にご記載ください（誤った案内は、当日ゲストが迷う原因になります）
- 会費・ご祝儀の額を記載する場合は、税込／税別の別と、当日の支払方法を正確にご記載ください
- 受賞歴・順位・口コミなど、確認できない情報は書かないでください。
  根拠のない「No.1」「◯◯％の方が満足」などの表示は景品表示法（優良誤認）違反となります
- **ゲストの個人情報について。** 出欠フォームで受け取った お名前・連絡先・アレルギーは、
  当日の手配にのみ使用し、式が終わったら削除してください。
  受信箱や回答一覧を、公開の場に載せないでください
- `assets/` に置く写真は、写っているご本人と撮影者（カメラマン）の許諾を得た素材をお使いください。
  ゲストが写り込んでいる写真を公開ページに載せる場合は、そのゲストの許可も取ってください
