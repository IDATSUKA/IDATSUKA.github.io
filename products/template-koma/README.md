# KOMA（コマ）— 写真家のためのギャラリーテンプレート v1.0

by IDATSUKA — https://idatsuka.com

白い壁と、広い余白。文字は小さく、絵は大きく。
写真家・イラストレーター・作家・工芸家のための、1ファイル完結の HTML テンプレートです。
ビルドツール・フレームワーク・外部ライブラリは一切不要。`index.html` を編集してアップロードするだけで公開できます。

サイトの中身は「作品を一枚ずつ見てもらう」ことだけに絞りました。
中心にあるのは**ライトボックス（拡大ビューア）**です。キーボード（← → Esc）、スワイプ、
読み上げソフトのすべてに対応しています。

## 使い方

1. `index.html` をテキストエディタで開く
2. ファイル冒頭のコメントに従い、`EDIT:` と書かれた箇所を自分の内容に差し替える
3. 写真を `assets/` に置く（`hero.jpg` / `work-01.jpg` … / `series-1.jpg` / `portrait.jpg`）
   置くまでの間は、その枠の縦横比のままのグレーのプレースホルダーが表示されます。**画像切れのアイコンは出ません**
4. `<style>` 内の `:root` の CSS 変数で配色を調整する（黒いテーマは `[data-theme="dark"]` ブロック）
5. サーバー（GitHub Pages / Netlify / レンタルサーバー等）に `index.html` と `assets/` をアップロード

### 最初に差し替える6か所

| 場所 | 内容 |
| --- | --- |
| `<title>` / `description` / `og:` / `canonical` | 作家名・ジャンル・地域・公開URL |
| Hero の `<h1 class="hero-name">` と `.hero-role` | 作家名と肩書き |
| `assets/hero.jpg` | HERO に置く代表作の1枚（2400×1600 程度） |
| WORKS の `<figure class="work">` × 12 | 作品名・制作年・撮影データ・画像（下の表を参照） |
| ABOUT の `.bio` と `.cv` | 略歴・個展・グループ展・受賞（**事実のみ**） |
| CONTACT の `.jobs` と `.contact-side` | 受けている仕事・料金・連絡先・SNS |

### 作品1枚の書きかた（WORKS）

作品の情報は、すべて `<figure>` の `data-` 属性に書きます。
ライトボックス（拡大表示）のキャプションは、ここから自動で作られます。**タイルだけ編集すれば済みます。**

```html
<figure class="work"
        data-title="◯◯の朝"                                  作品名
        data-year="20◯◯"                                     制作年
        data-meta="◯◯mm · f/◯.◯ · 1/◯◯◯s · ISO ◯◯◯"     撮影データ（自由な文字列）
        data-size="1600 × 2400">                             画像のピクセル数（横 × 縦）
  <button type="button" class="tile">
    <span class="frame" data-n="01">                         プレースホルダーに出る番号
      <img src="assets/work-01.jpg" alt="" loading="lazy">
    </span>
  </button>
  <figcaption><span class="cap-t">◯◯の朝</span><span class="cap-y">20◯◯</span></figcaption>
</figure>
```

| 属性 | 役割 |
| --- | --- |
| `data-title` | 作品名。ライトボックスの見出しと、サムネイルの読み上げ名になります |
| `data-year` | 制作年。作品名の右に小さく入ります |
| `data-meta` | 撮影データ。ライトボックスに等幅フォントで1行。焦点距離・絞り・シャッター速度・ISO を想定していますが、画材やサイズを書いても構いません |
| `data-size` | **横 × 縦のピクセル数。タイルの縦横比もこの値から計算されます**（`1600 × 2400` なら 2:3 の縦位置）。`1600x2400` でも読み取れます |
| `data-full`（任意） | 拡大表示のときだけ読み込む大きい画像のパス。省略するとサムネイルと同じ画像を使います |
| `data-n`（`.frame` 側） | 画像が無いときにプレースホルダーへ表示する番号 |

- 作品を増やすときは `<figure>` ごとコピーして、`data-n` を連番にするだけです（枚数は何枚でも構いません。カウンターの「12」も自動で変わります）
- 並びは CSS の `columns` によるメーソンリーです。**左の列を上から下へ、次の列へ**という順で並びます（1〜4枚目が左列、5〜8枚目が中央列…）
- 減らすときも `<figure>` ごと削除するだけです

### ライトボックス（拡大ビューア）の操作

| 操作 | 動き |
| --- | --- |
| サムネイルをクリック / Enter / Space | 開く |
| `←` `→` | 前後の作品へ（端まで行くと反対側へ回ります） |
| `Esc` | 閉じる（開いたサムネイルにフォーカスが戻ります） |
| `Tab` | ビューアの中（前へ・次へ・閉じる）だけを巡回します |
| 横スワイプ | 前後の作品へ |
| 下スワイプ | 閉じる |
| 画像の外側をクリック | 閉じる |

- 開いている間、背後のページはスクロールが止まり、読み上げソフトからも隠されます（`aria-hidden` / `inert`）
- 「3 / 12」は `aria-live` で読み上げられます
- 読み込むのは**表示中の1枚と、その前後2枚だけ**です（12枚を一度に読み込むことはしません）
- 動きを抑える設定（`prefers-reduced-motion`）のときは、フェードなしで即座に切り替わります

## テーマについて

- ナビ右上の「白／黒」で、白い壁（gallery）と暗い展示室（dark）の2テーマを切り替えられます（選択はブラウザに保存されます）
- 最初から黒で表示したい場合は `<html lang="ja" data-theme="gallery">` を `data-theme="dark"` に変更してください
- 切替ボタンが不要な場合は `#themeToggle` の `<button>` を削除してください
- `theme-color`（スマホのアドレスバーの色）は切替に追従します。色を変えたときは JavaScript 冒頭の `BAR` も合わせてください

| | 白（gallery） | 黒（dark） |
| --- | --- | --- |
| 地 `--bg` | `#fafafa` | `#0c0c0c` |
| 面 `--bg2` | `#f0f0f0` | `#161616` |
| 本文 `--fg` | `#111111` | `#ededed` |
| 赤 `--accent` | `#d7263d` | `#ff4d5e` |

赤（`--accent`）は**現在位置の印（ナビの下線）とフォーカスリングにしか使っていません**。
本文や見出しには使わないでください。壁に赤い文字は掛けない、という設計です。

## 特徴

- 1ファイル完結（HTML / CSS / JS すべて込み、外部ライブラリ・外部画像ゼロ）
- 白（壁）／黒（暗い展示室）の2テーマ切替、設定をブラウザに保存
- **ライトボックス**：キーボード操作（← → Esc）、フォーカストラップ、フォーカス復帰、スワイプ、`role="dialog"` / `aria-modal` / `aria-live`、背後のスクロール停止、前後2枚の先読み
- **メーソンリー**：CSS `columns` の3列 → 2列 → 1列。タイルは列をまたいで割れません（`break-inside: avoid`）
- **画像が無くても完成して見えます**：番号と推奨ピクセル数を印字したグレーの枠が、指定した縦横比のまま出ます。画像切れのアイコンは出ません
- 作品情報は `<figure>` の `data-` 属性ひとつにまとまっていて、キャプション・読み上げ名・縦横比が全部そこから作られます
- ホバー／フォーカスで出るキャプション（タッチ端末では常時表示）
- 3書体だけ（Archivo / Noto Sans JP / JetBrains Mono）、それぞれ日本語・欧文のフォールバック付き
- レスポンシブ（390px で確認済み・横スクロールなし）
- `prefers-reduced-motion` 対応（動きを抑える設定のユーザーにはフェードも停止し、すべてが最初から見えます）
- 印刷用スタイル（作品リストとして紙に出せます）
- OGP / canonical / theme-color / SVG ファビコン内蔵
- 日本語コメント付きで、HTML に不慣れな方でも差し替えやすい構成

## 掲載内容についてのお願い

- 作家名・作品名・年・撮影データ・価格・連絡先は、すべて「◯◯」「△△」「¥◯,◯◯◯」などのプレースホルダーです。公開前に必ず実際の内容へ差し替えてください
- **展示歴・受賞歴・掲載歴は、確認できる事実のみをご記載ください。** 実際には無い個展・入選・受賞・雑誌掲載を書くことは、景品表示法（優良誤認）に違反するおそれがあります。根拠のない「No.1」「日本初」などの表示も同様です
- 受賞歴が無い場合は、ABOUT の「受賞・掲載」ブロックごと削除して構いません。無い実績を埋めるより、作品を1枚増やすほうが効果があります
- **写真の著作権と、写っている方の肖像権（モデルリリースの取得）は、このテンプレートを使う方の責任です。** 人物・私有地・他者の作品（絵画・建築・商品など）が写っている場合は特にご注意ください
- このテンプレートには写真・イラスト・フォントファイルは同梱していません。`assets/` に置く素材は、ご自身が権利を持つ（または利用許諾を得た）ものをお使いください
- プリントやデータを販売する場合は、「特定商取引法に基づく表記」のページを別途ご用意ください
