# NOREN（暖簾）— 老舗のための Web サイトテンプレート v1.0

by IDATSUKA — https://idatsuka.com

明治・大正・昭和に創業したお店（茶舗・菓子舗・酒蔵・旅館・工房・呉服店など）のための、
1ファイル完結の和風 HTML テンプレートです。
ビルドツール・フレームワーク・外部画像は一切不要。`index.html` を編集してアップロードするだけで公開できます。

縦書きの屋号、揺れる暖簾、明治から令和までの年表 —— 「継いできた時間」がそのまま画面になるように作りました。

## 使い方

1. `index.html` をテキストエディタで開く
2. ファイル冒頭のコメントに従い、`EDIT:` と書かれた箇所を自分の店の内容に差し替える
3. `<style>` 内の `:root` のCSS変数で配色を調整する
   （夜テーマは `[data-theme="ink"]` ブロックで調整）
4. サーバー（GitHub Pages / Netlify / レンタルサーバー等）にアップロード

### 最初に差し替える5か所

| 場所 | 内容 |
| --- | --- |
| `<title>` / `description` / `og:` / `canonical` | 店名・業種・地域・公開URL |
| Hero の `<h1 class="hero-name">` | 屋号（1文字ずつ `<span class="ch">` で囲むと順に現れます） |
| Hero の `data-founded="1902"` | 創業年（和暦・Since・創業年数が自動で入ります） |
| `<symbol id="mon">` | 家紋（ここ1か所でナビ・暖簾・フッターすべてに反映されます） |
| 店舗案内の `<table class="info-table">` | 住所・電話・営業時間・定休日 |

### テーマについて

- ナビ右上の「昼／夜」で、和紙（paper）と墨（ink）の2テーマを切り替えられます（選択はブラウザに保存されます）
- 最初から夜で表示したい場合は `<html lang="ja" data-theme="paper">` を `data-theme="ink"` に変更してください
- 切替ボタンが不要な場合は `#themeToggle` の `<button>` を削除してください
- `theme-color`（スマホのアドレスバーの色）は切替に追従します

### 家紋・暖簾・落款

- **家紋**: `<symbol id="mon">` の中身を実際の家紋のパスに差し替えてください。画像を使う場合は各 `<svg><use href="#mon"></svg>` を `<img src="mon.svg" alt="">` に置き換えます
- **暖簾**: `.noren-panel` を増減すれば2枚・4枚にもできます。中央パネルの朱色の一文字（`.noren-char`）は屋号の一字に
- **落款（朱印）**: `.seal` の「印」を屋号の一文字に変えても綺麗に収まります
- 地図はプレースホルダーです。Googleマップ →「共有」→「地図を埋め込む」で得た `<iframe>` で `<div class="map">` ごと置き換えてください

## 特徴

- 1ファイル完結（HTML / CSS / JS すべて込み、外部ライブラリ・外部画像ゼロ）
- 和紙（昼）／墨（夜）の2テーマ切替、設定をブラウザに保存
- 縦書き対応：屋号・セクション見出し（一・二・三…）・引用の一節。900px 以下では自動で横書きに切り替わります
- 暖簾モチーフ：竿を支点にゆっくり揺れ、スクロールとホバーで少しだけ開きます
- 年表：明治→大正→昭和→平成→令和の帯。PCは横組み、スマホは縦組み。金の細罫がスクロールで伸び、項目が順に現れます
- 創業年は `data-founded` ひとつ。和暦・Since・創業年数を JavaScript が自動計算
- 和紙の繊維テクスチャ（SVG生成・静止）、朱のスクロール進捗線、下スクロールで隠れるナビ
- 品書き／店舗案内の表／地図プレースホルダー／お知らせ／FAQ（`<details>`）／お問い合わせ
- レスポンシブ（390px で確認済み・横スクロールなし）
- `prefers-reduced-motion` 対応（動きを抑える設定のユーザーには揺れもフェードも止まります）
- OGP / canonical / theme-color / SVG ファビコン内蔵
- 日本語コメント付きで、HTML に不慣れな方でも差し替えやすい構成

## 創業年の設定方法

Hero の1か所を書き換えるだけです。

```html
<p class="era-badge" data-founded="1902">
```

これだけで、

- 和暦　　　→「明治三十五年 創業」
- 西暦　　　→「Since 1902」
- 創業年数　→「創業 124 年」（今日の日付から自動計算）

がすべて自動で入ります。店舗案内の表とフッターにも同じ `data-founded="1902"` を書いた `<span>` があるので、
同じ年に揃えておいてください（そちらは「明治三十五年（1902年）創業」と表示されます）。

創業の月日までわかっている場合は、属性を足すとより正確になります。

```html
<p class="era-badge" data-founded="1912" data-founded-month="3" data-founded-day="15">
```

月日を指定すると、改元日をまたぐ年の判定と、創業年数の記念日前後の切り上げ・切り下げが正確になります。

## 元号変換の注意

対応している元号は次の5つです（明治より前の創業年は、和暦に変換せず西暦のまま表示されます）。

| 元号 | 期間 | 改元日 |
| --- | --- | --- |
| 明治 | 1868 — 1912 | 1868年1月25日 |
| 大正 | 1912 — 1926 | 1912年7月30日 |
| 昭和 | 1926 — 1989 | 1926年12月25日 |
| 平成 | 1989 — 2019 | 1989年1月8日 |
| 令和 | 2019 — | 2019年5月1日 |

**改元年の扱い（重要）**

`data-founded` に「年」だけを指定した場合、改元のあった年（1912 / 1926 / 1989 / 2019）は
**新しい元号の元年**として表示します。

- `data-founded="1912"` → **大正元年**（明治45年ではありません）
- `data-founded="1926"` → 昭和元年
- `data-founded="1989"` → 平成元年
- `data-founded="2019"` → 令和元年

旧元号で表記したい場合（例：1912年3月創業＝明治45年）は、`data-founded-month` を足してください。
改元日より前なら自動で旧元号に切り替わります。

```html
data-founded="1912" data-founded-month="3"   <!-- → 明治四十五年 -->
data-founded="1912" data-founded-month="8"   <!-- → 大正元年 -->
```

その他の仕様

- 元年は漢数字ではなく「元」と表示します（例：令和元年）
- 元号の年は漢数字（例：明治三十五年）、西暦と創業年数はアラビア数字で表示します
- 創業年数は「今日の日付 − 創業年」です。月日を指定しない場合は年の差だけで計算します
- 年表の元号見出し（明治・大正…）は自動計算ではなく、そのまま編集できる文字です

## 掲載内容についてのお願い

- 店名・人物名・住所・電話・価格・年表の内容は、すべて「◯◯」「△△」「¥0,000」などのプレースホルダーです。公開前に必ず実際の内容へ差し替えてください
- 受賞歴・実績・口コミは、**確認できる事実のみ**をご記載ください（景品表示法／優良誤認の観点から、根拠のない「日本一」「最高級」などの表現はお避けください）
- 食品を扱う場合は消費期限・保存方法の表示（食品表示法）、通信販売を行う場合は「特定商取引法に基づく表記」のページを別途ご用意ください
- 埋め込み地図は Google マップの利用規約に従ってご利用ください
