# KARTE（カルテ）— クリニック・医院のための Web サイトテンプレート v1.0

by IDATSUKA — https://idatsuka.com

内科・歯科・整形外科・皮膚科・耳鼻科・小児科・整骨院など、
小さな医院のための1ファイル完結の HTML テンプレートです。
ビルドツール・フレームワーク・外部ライブラリは一切不要。
`index.html` を編集してアップロードするだけで公開できます。

医院のサイトを訪れた人が知りたいことは、だいたい4つです。

1. 信頼できる医院か
2. 今日は開いているか
3. どうやって行くか
4. どう予約するか

KARTE は、その4つに最短で答えることだけを考えて作りました。
派手な動きはありません。このラインで一番おとなしいテンプレートで、それが正解だと考えています。

## 使い方

1. `index.html` をテキストエディタで開く
2. ファイル冒頭のコメントに従い、`EDIT:` と書かれた箇所を自分の医院の内容に差し替える
3. `<style>` 内の `:root` の CSS 変数で配色を調整する
   （夜間テーマは `[data-theme="dark"]` ブロックで調整）
4. 写真を使う場合は `assets/` に置く（置かなくても成立する画面になっています）
5. サーバー（GitHub Pages / Netlify / レンタルサーバー等）にアップロード

### 最初に差し替える6か所

| 場所 | 内容 |
| --- | --- |
| `<title>` / `description` / `og:` / `canonical` | 医院名・診療科・地域・公開URL |
| `<table class="hours">` の `data-hours` / `data-reception` | 診療時間（表・スマホ表示・本日の強調・受付状況が、ここから全部作られます） |
| `<a href="tel:0000000000">` の3か所 | 電話番号（ヘッダー下のボタン／下部の固定バー／アクセス欄・フッター） |
| `WEB予約はこちら` の `href="#"` の2か所 | 予約システムのURL（HERO と下部の固定バー） |
| HERO の `<h1>` と診療科のタグ `.chip` | 医院名・診療科 |
| アクセスの `<table class="info-table">` と地図 | 住所・最寄駅・駐車場・Googleマップの埋め込み |

## 診療時間表の書き方（このテンプレートの中心）

書き換えるのは `<table class="hours">` の属性だけです。
**PCの表・スマホのカード表示・「本日」の強調・受付状況の一行**は、すべてここから作られます。

### 1. `data-hours` — 表に出る印

```html
data-hours='{"mon":{"am":"○","pm":"○"},"wed":{"am":"○","pm":"ー"},"sat":{"am":"○","pm":"△"},"sun":{"am":"ー","pm":"ー"}}'
```

- キーは `mon` `tue` `wed` `thu` `fri` `sat` `sun`、その中が `am`（午前）と `pm`（午後）
- 値は `"○"`（診療）・`"△"`（一部診療）・`"ー"`（休診）。ほかの記号を入れてもそのまま表示されます
- `△` の意味は医院によって違うので、表の下の**凡例を必ず書き換えてください**（例：土曜の午後は16:00まで）

### 2. `data-reception` — 実際の受付時間

```html
data-reception='{"mon":{"am":"09:00-12:30","pm":"15:00-18:30"},"wed":{"am":"09:00-12:30","pm":""},"sun":{"am":"","pm":""}}'
```

- 形式は `"09:00-12:30"`。休みの半日は `""`（空文字）にしてください
- この時間から、上の「受付状況」の一行が計算されます
- スマホ表示の各カードに出る時間も、ここから自動で入ります（`data-time`）

### 3. `data-closed` — 臨時休診・学会休診の日（任意）

```html
data-closed='["2026-09-21","2026-12-29"]'
```

この日は受付状況が「本日は休診日です（臨時休診）」になります。
**祝日は自動判定しません。** 祝日に休診する場合も、この配列に足すか、表の下の備考とお知らせに明記してください。

### 受付状況の一行について

`data-reception` の時間と、今の時刻から、次のように表示が変わります。

| 状況 | 表示 |
| --- | --- |
| 受付時間内 | 受付中（午前の受付は 12:30 まで） |
| 午前が終わり、午後の前 | 午前の受付は終了しました（午後は 15:00 から） |
| 開院前 | 本日の受付は 09:00 からです |
| 本日の受付が全部終わった | 本日の受付は終了しました |
| その曜日が休診／`data-closed` に該当 | 本日は休診日です |

**属性が無い、または書式が壊れている場合は、この一行を丸ごと隠します**（誤った情報を出さないためです）。
表そのものは、そのまま表示されます。

### スマホでの表示

640px 以下では、同じ `<table>` が**曜日ごとのカード**に組み替わります。
HTML は1つだけで、CSS が行と列を入れ替えているので、書き換える場所も1か所だけです。

表示が変わっても `role="table"` `role="row"` `role="columnheader"` `<th scope="col|row">` は
そのまま残してあるので、スクリーンリーダーでは表として読み上げられます。
実際、スマホ幅では各セルが「午前・診療・09:00–12:30」、曜日の見出しが「月曜日」と読み上げられます
（`○ △ ー` の記号は読み上げに向かないため、読み上げ用の言葉を別に入れてあります。
表の見た目を CSS で組み替えると表の意味が失われるブラウザがあるので、`role` を明示しています）。

### JavaScript が無効な場合

表のセルには、あらかじめ同じ印を書いてあります（`data-hours` の内容と揃えてあります）。
JavaScript が使えない環境では、この控えがそのまま表示されます。
`data-hours` を書き換えれば表示はそちらに合わせて変わりますが、
両方そろえておきたい場合は、HTML 側の印も同じに直しておいてください。

## テーマについて

- ヘッダー右上の「標準／夜間」で2テーマを切り替えられます（選択はブラウザに保存されます）
- **夜間テーマは飾りではありません。** 夜間や休日に「今日は開いているか」「電話番号は何番か」を
  暗い部屋のスマホで確認する人のための、実用的なアクセシビリティ機能として入れています。
  急に具合が悪くなったときに、まぶしい白い画面を突きつけないためのものです
- 最初から夜間で表示したい場合は `<html lang="ja" data-theme="light">` を `data-theme="dark"` に変更してください
- 切替ボタンが不要な場合は `#themeToggle` の `<button>` を削除してください
- `theme-color`（スマホのアドレスバーの色）は切替に追従します
- 本文の文字は、どちらのテーマでもコントラスト比 4.5:1 以上を確保しています

## 書体について

3種類だけを使っています（すべて Google Fonts）。

| 用途 | 書体 | 理由 |
| --- | --- | --- |
| 日本語（本文・見出し） | **BIZ UDPGothic** | ユニバーサルデザイン書体です。濁点・半濁点が大きく、「6」と「8」「ソ」と「ン」のような紛らわしい字が判別しやすい字形になっています。高齢の患者さんが多い医院のサイトで、最初に効く選択です |
| 英数字 | IBM Plex Sans | 日本語と並べたときに線の太さが揃い、落ち着いて見えます |
| 数字・時刻・ラベル | IBM Plex Mono | 電話番号と診療時間は等幅にすると桁が揃い、読み違いが減ります |

いずれもフォールバック（ヒラギノ・游ゴシック・メイリオ等）を指定しているので、
読み込みに失敗しても崩れません。

## 特徴

- 1ファイル完結（HTML / CSS / JS すべて込み、外部ライブラリゼロ）
- 標準／夜間の2テーマ切替、設定をブラウザに保存、`theme-color` 同期、描画前に適用（ちらつきなし）
- 診療時間表：1つのデータから、PCは本物の `<table>`、スマホは曜日カードに自動で組み替え
- 本日の列を自動で強調し、「本日」の札を表示
- 受付状況の一行（受付中／午前の受付は終了しました／本日は休診日です）を自動計算
- 臨時休診日（`data-closed`）に対応
- 電話ボタンは大きく、番号は等幅。スマホには「電話する／WEB予約」の固定バー
- スマホでは、医院名・受付状況・電話を先に表示し、写真はその下に置きます
- Tabキーで現れる「診療時間へ移動」のスキップリンク、押しやすい大きさのボタン（最小56px）
- 写真が無くても成立する画面（グラデーションの枠。画像切れのアイコンは出ません）
- レスポンシブ（390px で確認済み・横スクロールなし）
- `prefers-reduced-motion` 対応（動きを抑える設定のユーザーにはフェードも止まり、すべて表示されます）
- OGP / canonical / theme-color / SVG ファビコン内蔵
- 日本語コメント付きで、HTML に不慣れな方でも差し替えやすい構成

## 掲載内容についてのお願い

医院名・医師名・経歴・所属学会・住所・電話番号・日付・料金は、すべて「◯◯」「△△」等の
プレースホルダーです。公開前に必ず実際の内容へ差し替えてください。

## 医療広告ガイドラインについて（重要）

**医療機関のウェブサイトは「医療広告」として規制の対象です**（医療法／医業若しくは歯科医業又は
病院若しくは診療所に関する広告等に関する指針）。一般の業種のサイトと同じ感覚で書くと、
そのまま違反になります。このテンプレートで一番気をつけていただきたい点です。

### 書けないこと

- **治療効果に関する表現**
  「必ず治る」「痛くない」「◯◯が改善します」「安心・安全」など
- **体験談・患者さんの感想**
  治療内容や効果に関する体験談は、ウェブサイトにも掲載できません
- **誇大・優良誤認の表現**
  「日本一」「最高」「No.1」「◯◯で評判」「県内唯一」（客観的事実として証明できる場合を除く）
- **他院との比較**
  「◯◯クリニックより安い」「地域で最も◯◯」など

### 条件つきで書けること

- **自由診療（保険適用外）** — 掲載する場合は、次の明示が必要です
  1. 標準的な費用（総額）
  2. 治療期間・回数
  3. 主なリスクと副作用
  4. 保険診療ではないこと（未承認医薬品等を用いる場合はその旨も）
- **ビフォーアフター写真** — **単独掲載は不可**です。
  通常必要とされる治療内容・標準的な費用・主なリスクと副作用の説明を、必ず併記してください
- **医師名・経歴・所属学会・専門医資格・症例数** — すべて**確認できる事実のみ**。
  「専門医」「指導医」は、実際に認定を受けている資格だけが記載できます

### このテンプレートのデモ文について

デモの文章は、上のいずれにも当たらない書き方にしてあります
（「何を診るか」「どう進めるか」を事実として書き、効果や優位性には触れていません）。
書き換えるときも、同じ線を越えないようにしてください。

最新の指針は厚生労働省のウェブサイトでご確認ください。判断に迷う表現は、
各都道府県の医療安全支援センター・保健所にご相談いただくのが確実です。

### そのほか

- 埋め込み地図は Google マップの利用規約に従ってご利用ください
- 写真（院内・スタッフ・患者さん）は、ご自身が権利を持つ（または許諾を得た）ものをお使いください。
  患者さんが写り込む写真は、必ず同意を得てから掲載してください
- 個人情報を扱うお問い合わせフォームを設置する場合は、プライバシーポリシーのページを別途ご用意ください
