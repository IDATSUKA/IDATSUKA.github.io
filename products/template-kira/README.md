# KIRA（キラ）— Character & Creator Template v1.0

by IDATSUKA — https://idatsuka.com

VTuber・イラストレーター・同人サークル・キャラクターIP・マスコットのいるインディーゲームのための、
1ファイル完結のアニメ／萌え系 HTML テンプレートです。
ビルドツール・フレームワーク・外部画像は一切不要。`index.html` を編集してアップロードするだけで公開できます。

ステッカー風のカード、吹き出し、波形の区切り、集中線、舞うキラキラ —— 「公式サイトらしい賑やかさ」を、
読みやすさを落とさずに詰め込みました。キャラクターのイラスト（仮）も SVG で収録しているので、
差し替え用の絵がまだ無い状態でも、そのまま置いて形になります。

## 使い方

1. `index.html` をテキストエディタで開く
2. ファイル冒頭のコメントに従い、`EDIT:` と書かれた箇所を自分の内容に差し替える
3. `<style>` 内の `:root` のCSS変数で配色を調整する
   （夜テーマは `[data-theme="night"]` ブロックで調整）
4. サーバー（GitHub Pages / Netlify / レンタルサーバー等）にアップロード

### 最初に差し替える5か所

| 場所 | 内容 |
| --- | --- |
| `<title>` / `description` / `og:` / `canonical` | 名前・肩書き・活動内容・公開URL |
| Hero の `<h1 class="hero-name">` と `.hero-romaji` | キャラクター名（日本語）とローマ字表記 |
| Hero の `<svg class="hero-art">` | キャラクターのイラスト（`<img>` に置き換えるだけ） |
| PROFILE の `<table class="prof-table">` | 誕生日・身長・イメージカラー・ファンネーム等 |
| LINKS の `<a class="link-btn">` の `href` | 各SNS・ショップのURL |

### テーマについて

- ナビ右上の「☀／☾」で、ポップ（pop）とナイト（night）の2テーマを切り替えられます（選択はブラウザに保存されます）
- 最初から夜で表示したい場合は `<html lang="ja" data-theme="pop">` を `data-theme="night"` に変更してください
- 切替ボタンが不要な場合は `#themeToggle` の `<button>` を削除してください
- `theme-color`（スマホのアドレスバーの色）は切替に追従します

### 配色を変える

`:root` の CSS 変数を書き換えるだけで、全体の印象が変わります。

```css
--pink:   #ff85b3;   /* メイン。見出しの下線・ボタン・リボンに使われます */
--sky:    #6fcbff;   /* サブ */
--lemon:  #ffe066;   /* ラベル・チップ */
--mint:   #8fe3c4;
--lav:    #c9b8ff;
--line:   #2a2240;   /* ステッカーの枠線とずらした影の色 */
```

本文の文字色（`--fg`）は、明るい地の上でも読めるよう十分に濃い色にしてください。
パステルカラーは「面・枠・飾り」用で、本文には使わない設計になっています。

### キャラクターイラストの差し替え

Hero のこの1行を置き換えるだけです。

```html
<!-- 差し替え前 -->
<svg class="hero-art" viewBox="0 0 400 520" aria-hidden="true"><use href="#chara"></use></svg>

<!-- 差し替え後 -->
<img class="hero-art" src="chara.png" alt="">
```

- 縦長・横長どちらの画像でも崩れないように CSS 側で調整済みです（`object-fit: contain`）
- 背景を透過した PNG / WebP がおすすめです
- 収録している `<symbol id="chara">` のイラストは、このテンプレート用に描き起こした仮のキャラクターです。
  自由に使っていただけますが、そのまま公式キャラクターとして使うことは想定していません
- **ご自身が権利を持つ（または利用許諾を得た）イラストをお使いください。**
  権利を持っていない他者のキャラクター・アニメ・ゲームの画像は掲載できません

### イラスト枠・商品画像の差し替え

- ギャラリー：各 `<div class="tile-img">…</div>` を `<img src="art1.jpg" alt="◯◯">` に置き換え。
  枠の比率は `.tile-img` の `aspect-ratio: 4 / 3` で変えられます
- グッズ：各 `<div class="goods-img">…</div>` を `<img src="goods1.jpg" alt="">` に置き換え（正方形推奨）

### ボイスを実際に鳴らすには

VOICE セクションの再生ボタンは見た目だけのプレースホルダーです。
実際に音を出したい場合は、各カードの中に `<audio>` を追加するのがいちばん簡単です。

```html
<audio controls preload="none" src="voice1.mp3"></audio>
```

## 特徴

- 1ファイル完結（HTML / CSS / JS すべて込み、外部ライブラリ・外部画像ゼロ）
- ポップ（昼）／ナイト（夜）の2テーマ切替、設定をブラウザに保存
- キャラクターのイラストを SVG で収録（`<img>` に差し替え可）
- ヒーロー：集中線がゆっくり回り、キャラクターがふわふわ揺れ、マウスを動かすと奥行きごとに視差でずれます
- キャラクターをクリック／タップすると「ぽよん」と弾んで、ハートと星が飛び散ります
- ふわふわ舞うキラキラ（Canvas・最大40粒）。粒はあらかじめ小さな画像に描いてから貼る方式で、影を使わないので軽いです。タブを離れているあいだは停止します
- PC（マウスのある端末）だけ、カーソルにキラキラの軌跡がつきます
- ステッカー風のカード（2.5px の枠＋ずらした影。ホバーで浮きます）、斜めのリボンラベル、しっぽ付きの吹き出し
- 波形のセクション区切り（SVG）、水玉・斜めストライプの背景（CSS グラデーションのみ）
- 流れるお知らせティッカー（ホバーで一時停止）
- パラメータバーはスクロールで伸び、カードは少し行き過ぎて戻るイージングで現れます
- 週間スケジュール（PCは7列、スマホは縦積みリストに自動で切替）
- レスポンシブ（390px で確認済み・横スクロールなし）
- `prefers-reduced-motion` 対応（動きを抑える設定のユーザーには、キラキラもカーソル軌跡も揺れも止まり、内容は最初から表示されます）
- 本文のコントラストは 4.5:1 以上（明・暗どちらのテーマでも確認済み）
- OGP / canonical / theme-color / SVG ファビコン内蔵
- 日本語コメント付きで、HTML に不慣れな方でも差し替えやすい構成

## 掲載内容についてのお願い

- 名前・日付・価格・数値は、すべて「◯◯」「¥◯,◯◯◯」などのプレースホルダーです。公開前に必ず実際の内容へ差し替えてください
- **登録者数・再生数・販売実績・受賞歴・ファンの声は、確認できる事実のみをご記載ください。**
  根拠のない「No.1」「日本一」「大人気」などの表現は、景品表示法（優良誤認）の観点からお避けください
- PROFILE のパラメータバー（うた・ゲーム・トーク・えがく）は、キャラクター設定上の演出です。
  実際の能力や実績を数値で断定する表現にはしないでください
- グッズの価格は税込表示にしてください。通信販売を行う場合は「特定商取引法に基づく表記」のページを別途ご用意ください
- イラストは、ご自身が権利を持つ（または利用許諾を得た）ものだけをお使いください。
  他者のキャラクター・アニメ・ゲームの画像は掲載できません
- 二次創作ガイドラインは例文です。実際の方針に書き換えてから公開してください
- LINKS のアイコンは汎用の線画で、各社のロゴではありません。公式ロゴを使う場合は、各社のブランドガイドラインに従ってください
