FAQ

コーディング知識は必要ですか？

テキスト編集ができれば十分です。EDIT コメントと CSS 変数だけで見た目と文言を変えられます。

ZEN との違いは？

ZEN はポートフォリオ向け。RAY は1オファーの LP 向けで、セクションが短く、アクセントとモーションで視線誘導を強めにしています。

実績数字やクライアント名を載せてもいいですか？

検証できるもの・公開許可があるものだけにしてください。想定案件は Spec / Concept / Personal と明示し、捏造は避けてください。
