# VEIL（ヴェール）— 没入型ブランドサイト テンプレート v1.0

by IDATSUKA — https://idatsuka.com

一枚の写真（または動画）が画面いっぱいに広がり、その上にすりガラスの UI が浮かぶ——
「絵が主役、文字は最小限」のブランドサイト用 HTML テンプレートです。

ビルドツール・フレームワーク・外部ライブラリは一切不要。`index.html` を編集して、
`assets/` に写真を1〜2枚置いてアップロードするだけで公開できます。

写真が1枚あれば成立するように作りました。スタジオ・アトリエ・建築・プロダクト・
ホテル・ギャラリー・美容室など、「見せたい絵がある」仕事のためのテンプレートです。

**写真がまだ無くても大丈夫です。** 画像を置かなかった場合は CSS のグラデーション
（夜＝夕暮れ／昼＝クリーム）がそのまま背景になり、画像切れのアイコンは出ません。
先にテキストを入れて公開し、あとから写真を差し替える使い方ができます。

## 使い方

1. `index.html` をテキストエディタで開く
2. ファイル冒頭のコメントに従い、`EDIT:` と書かれた箇所を自分の内容に差し替える
3. `<style>` 内の `:root` の CSS 変数で配色を調整する
   （昼テーマは `[data-theme="studio"]` ブロックで調整）
4. 写真を `assets/` に置く（任意。置かなければグラデーションになります）
5. サーバー（GitHub Pages / Netlify / レンタルサーバー等）に `index.html` と `assets/` をアップロード

### 最初に差し替える6か所

| 場所 | 内容 |
| --- | --- |
| `<title>` / `description` / `og:` / `canonical` | 屋号・業種・地域・公開URL |
| `assets/hero.jpg` | 主役の写真（2400×1500 程度）。置かない場合はグラデーション |
| HERO の `<h1 class="h1 display focus-pull">` | 見出し2行（読み込み時にぼけから合焦します） |
| HERO の `.eyebrow` と `.hero-sub` | 小見出し（• のあと）と、1文の説明 |
| `.nav-wordmark` の `VEIL`（ナビとフッターの2か所） | 自分の屋号・ロゴ文字 |
| `.stat-strip` の3つの数字 | 実際に確認できる数字に（詳細は「掲載内容についてのお願い」） |

### テーマについて

- ナビの「Cinema／Studio」で、夜（cinema）と昼（studio）の2テーマを切り替えられます（選択はブラウザに保存されます）
- 最初から昼で表示したい場合は `<html lang="ja" data-theme="cinema">` を `data-theme="studio"` に変更してください
- 切替ボタンが不要な場合は `#themeToggle` の `<button>` を削除してください
- `theme-color`（スマホのアドレスバーの色）は切替に追従します。色を変えたときは JS 内の `BAR = { cinema: '...', studio: '...' }` も合わせてください

2つのテーマは、同じレイアウトのまま別の世界になるように作ってあります。

| | Cinema（夜・初期値） | Studio（昼） |
| --- | --- | --- |
| 地 | `#0a0b0d` | `#f4efe9`（クリーム） |
| 文字 | `#f4f2ee` | `#1c1a18` |
| ガラス | `rgba(255,255,255,.07)` | `rgba(255,255,255,.55)` |
| アクセント | `#f6efe6`（温かい白／色のアクセント無し） | `#c9703f`（テラコッタ） |
| 大見出し | サンセリフ（Instrument Sans） | セリフ（Instrument Serif／日本語は明朝） |
| 背景グラデーション | 夕暮れ | クリーム＋陶土色 |

### 写真・動画の差し替え

| ファイル | 使う場所 | 推奨サイズ |
| --- | --- | --- |
| `assets/hero.jpg` | HERO 全面 | 2400×1500 程度 |
| `assets/hero.mp4` / `.webm` | HERO を動画にする場合 | 1920×1080 のループ素材 |
| `assets/showcase.jpg` | SHOWCASE の大きい帯 | 2400×1200 程度 |
| `assets/showcase-2.jpg` / `-3.jpg` | SHOWCASE の小さい帯2つ | 1400×900 程度 |

- 動画にする場合は、HERO の `<img class="stage-img">` を削除し、その下の `<video class="stage-video">` のコメントを外してください
- 動画は `prefers-reduced-motion`（動きを抑える設定）のときは自動的に停止します
- 同梱している写真・動画・フォントファイルはありません。`assets/` に置く素材は、ご自身が権利を持つ（または利用許諾を得た）ものをお使いください

### すりガラスの部品（グラスキット）

このテンプレートの中心です。クラスを付けるだけでどこでも使えます。

| クラス | 何か |
| --- | --- |
| `.glass` | すりガラスの地。`+ .glass-pill`（丸） または `+ .glass-card`（角丸18px） |
| `.nav-pill` | 上に浮かぶピル型のナビ。24px スクロールすると少し縮んで濃くなります |
| `.pill` / `.pill-solid` / `.pill-ghost` / `.pill-sm` | ボタン。高さは最低44pxを確保しています |
| `.eyebrow` | `• ◯◯` の形の小見出し（等幅・大文字・字間広め） |
| `.panel` | 浮遊データパネル（見出し＋2行＋スパークライン） |
| `.bubble` / `.bubble-alt` | 小さな吹き出し。`.bubble-in` を足すと順に浮かび上がります |
| `.crosshairs` + `.crosshair` | 四隅の `+` の印。`.ch-tl` / `.ch-tr` / `.ch-bl` / `.ch-br` |
| `.stat-strip` + `.stat` | 数字の帯（細い罫で区切り） |
| `.rv` | スクロールで、ぼけながら現れる（どの要素にも付けられます） |

**暗い写真の上でもガラスが消えない仕組み**：`.glass` は `--glass`（半透明の地）の下に
`--glass-scrim`（うっすらした膜）を敷いています。この膜があるおかげで、真っ暗な写真の上でも
真っ白な写真の上でも、ガラスの形と中の文字が必ず読めます。ガラスをもっと透明にしたい場合は
`--glass-scrim` の数値を下げてください（下げすぎると写真によっては文字が読めなくなります）。

### HERO の演出を調整する

| 演出 | 調整する場所 |
| --- | --- |
| 灯りが順に点る | `.stage-glow i:nth-child()` の `left` / `top` / `width` / `height` / `animation-delay`。写真の窓の位置に合わせると効果的です |
| 灯りの色・強さ | `--glow-color` / `--glow-blend` |
| ゆっくり寄る（Ken Burns） | `.stage-media` の `animation: kenburns 28s ...` と `@keyframes kenburns` の `scale` |
| 舞う塵 | JS の `COUNT: 30〜50`（`build()` 内）、色は `--fx-rgb` / `--fx-alpha` |
| マウス視差 | JS の `MAX = 14`（px）と、各要素の `data-depth` |
| 見出しのフォーカスプル | `@keyframes focusPull` の `blur(14px)` と時間 |
| 絵の上の膜（文字の読みやすさ） | `--hero-scrim` / `--hero-shadow` / `--hero-fg` |

暗い写真を昼（studio）テーマで使う場合は、`[data-theme="studio"]` の `--hero-fg` を
明るい色に変えてください（絵の上の文字だけが変わります）。

## 特徴

- 1ファイル完結（HTML / CSS / JS すべて込み、外部ライブラリゼロ）
- 夜（cinema）／昼（studio）の2テーマ切替、設定をブラウザに保存、`theme-color` も同期
- すりガラスキット（ピルナビ／ボタン／データパネル／吹き出し／クロスヘア／統計ストリップ）
- HERO：灯りがひとつずつ点っていく光の層（約6秒で巡回）、28秒かけてゆっくり寄る Ken Burns、
  舞い上がる塵（Canvas・30〜50粒）、マウス視差（PCのみ・最大14px・層ごとに深さ違い）、
  見出しのフォーカスプル（ぼけ→合焦）
- 塵の描画は事前に描いた1枚のスプライトを貼るだけの軽量実装。画面外・別タブでは停止します
- 写真が無くてもグラデーションで完成して見える（画像切れのアイコンを出しません）
- 流れる帯（ティッカー・CSSのみ／hover で停止）、全幅のショーケース帯、統計ストリップ、引用
- 3ファミリーのフォント（Instrument Sans / Instrument Serif / DM Mono）、すべてフォールバック指定つき
- レスポンシブ（390px で確認済み・横スクロールなし）
- `prefers-reduced-motion` 対応（動きを抑える設定では演出を止めて、全要素をそのまま表示します）
- 本文コントラスト 4.5:1 以上を両テーマで確認済み
- OGP / canonical / theme-color / SVG ファビコン内蔵
- 日本語コメント付きで、HTML に不慣れな方でも差し替えやすい構成

## セクション構成

| # | セクション | 内容 |
| --- | --- | --- |
| 1 | HERO | 全面の絵、小見出し、2行の見出し、1文の説明、ボタン2つ、データパネル、吹き出し2つ、四隅のクロスヘア、スクロール表示 |
| 2 | TICKER | 細い流れる帯（`◯◯◯◯ ✦ ◯◯◯◯ …`）。hover と reduced-motion で止まります |
| 3 | INTRO | 大きな一文＋短い段落2つ＋右のメタ列（`EST. ◯◯◯◯` / `◯◯ / ◯◯`） |
| 4 | SERVICES | すりガラスのカード3枚（番号・見出し・2行・線画アイコン） |
| 5 | WORK | 全幅の絵の帯＋浮かぶキャプション＋`01 / 03` の表示。下に2つ並び |
| 6 | STATS | 数字の帯3つ（`◯◯K+` / `◯◯M+` / `◯◯.◯%`） |
| 7 | VOICE | 大きな引用（セリフ体イタリック）と、誰の言葉かの1行 |
| 8 | CONTACT | 全幅のパネル、1行のコピー、ボタン1つ |
| 9 | FOOTER | ロゴ、リンク3列、著作権表記 |

ナビのリンクは WORK / ABOUT / SERVICES / CONTACT ＋ テーマ切替 ＋ CTA。
1000px 以下では全画面のガラスメニューになります。

## 掲載内容についてのお願い

- 屋号・人物名・住所・数字・価格・年・事例の内容は、すべて「◯◯」「△△」「¥◯,◯◯◯」「◯◯K+」などのプレースホルダーです。公開前に必ず実際の内容へ差し替えてください
- **STATS の数字（`◯◯K+` / `◯◯M+` / `◯◯.◯%`）は、必ず実際に確認できる値にしてください。** 導入社数・利用者数・稼働率・満足度などを、根拠なく大きく見せると景品表示法（優良誤認）違反となります
- **VOICE（お客様の声）に、実在しないコメントを載せないでください。** 掲載するときは、必ずご本人の許諾を得た実際の言葉を使ってください。自作のレビューや、架空の企業名・人名での推薦は違法となる可能性があります
- 受賞歴・実績・フォロワー数・売上も同様です。根拠のない「No.1」「業界最高」「◯◯％の方が満足」などの表示はお避けください
- WORK の事例に、実在する企業名を許諾なく掲載しないでください
- 価格を掲載する場合は、税込／税別の別を明記してください。通信販売を行う場合は「特定商取引法に基づく表記」のページを別途ご用意ください
- `assets/` に置く写真・動画は、ご自身が権利を持つ（または利用許諾を得た）素材をお使いください
