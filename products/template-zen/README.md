# ZEN — Minimal Portfolio Template v1.1

by IDATSUKA — https://idatsuka.com

1ファイル完結のミニマルなポートフォリオHTMLテンプレートです。
ビルドツール・フレームワーク不要。`index.html` を編集してアップロードするだけで公開できます。

## 使い方

1. `index.html` をテキストエディタで開く
2. ファイル冒頭のコメントに従い、`EDIT:` と書かれた箇所を自分の内容に差し替える
3. `<style>` 内の `:root` のCSS変数で配色・フォントを調整する
   （ライトテーマは `[data-theme="light"]` ブロックで調整）
4. サーバー（GitHub Pages / Netlify / レンタルサーバー等）にアップロード

### 画像の入れ方

- 実績カード・プロフィール写真は、コメントアウトされている `<img>` を解除して `src` を差し替えるだけです
- 画像を入れるまでは CSS で生成したプレースホルダーが表示されるので、未完成でも見栄えが崩れません
- 実績カードは複製するだけで番号（01, 02…）が自動で振られます

### テーマについて

- ナビ右上のボタンでダーク / ライトを切り替えられます（選択はブラウザに保存されます）
- 最初からライトで表示したい場合は `<html lang="ja">` を `<html lang="ja" data-theme="light">` に変更してください
- 切替ボタンが不要な場合は `.theme-btn` の `<button>` を削除してください

## 特徴

- 1ファイル完結（HTML / CSS / JS すべて込み、依存なし）
- レスポンシブ対応（720px 以下はハンバーガーメニュー）
- ダーク / ライト切替（設定をブラウザに保存）
- Hero の行ごとのマスク表示、ゆっくり漂う環境光、Scroll インジケータ
- スクロール連動のリビールアニメーション（ブラー付き・順番に表示）
- スクロール進捗ライン、下スクロールで隠れるナビ
- CSS 生成のプレースホルダー（実績サムネイル・プロフィール写真）
- `prefers-reduced-motion` 対応（動きを抑える設定のユーザーにはアニメーションを停止）
- OGP / theme-color / SVG ファビコン内蔵
- 日本語コメント付きで初心者でもカスタマイズしやすい
