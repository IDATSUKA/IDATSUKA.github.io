# UTAGE（宴）— イベント・ライブのための Web サイトテンプレート v1.0

by IDATSUKA — https://idatsuka.com

ライブ、小さな音楽フェス、クラブナイト、文化祭、マルシェ、展示のオープニング ——
**一回きりのイベント**のための、1ファイル完結の告知サイトテンプレートです。
ビルドツール・フレームワーク・外部ライブラリは一切不要。`index.html` を編集してアップロードするだけで公開できます。

三か月だけ全力で立ち、終わったら記録になる。そういうページです。
だから、いつ／どこで／誰が出る／いくら／どう買う、の5つを、上から順に、大きな声で答えることだけを考えて作りました。

中心にあるのは**タイムテーブル**です。`data-start` と `data-end` を書くだけで、PC では「時刻 × ステージ」のグリッドに、
スマホではステージ切替の縦リストになります。出演が重なれば自動で左右に分かれます。

## 使い方

1. `index.html` をテキストエディタで開く
2. ファイル冒頭のコメントに従い、`EDIT:` と書かれた箇所を自分のイベントの内容に差し替える
3. `<style>` 内の `:root` のCSS変数で配色を調整する
   （明るいテーマは `[data-theme="paper"]` ブロックで調整）
4. サーバー（GitHub Pages / Netlify / レンタルサーバー等）に `assets/` ごとアップロード

### 最初に差し替える6か所

| 場所 | 内容 |
| --- | --- |
| `<title>` / `description` / `og:` / `canonical` | イベント名・日付・会場・公開URL |
| Hero の `<h1 class="hero-title">` | イベント名（英字は Anton で画面いっぱい／日本語は `.stroke` の行へ） |
| Hero の `<dl class="hero-facts">` | 日付・開場/開演・会場（**ここが一番読まれます**） |
| Hero の `data-when="2027-09-18T18:00+09:00"` | 開場の日時。カウントダウンが自動で動きます |
| `<div class="tt" data-stages data-open data-close>` とその中の `.act` | タイムテーブル（下に詳しく） |
| TICKET の `<article class="tk">` 3枚 | 券種・価格・発売日・購入ボタンの URL |

### テーマについて

- ナビ右上の「NEON／PAPER」で、暗い（neon）と明るい（paper）の2テーマを切り替えられます（選択はブラウザに `utage-theme` として保存されます）
- 最初から明るく表示したい場合は `<html lang="ja" data-theme="neon">` を `data-theme="paper"` に変更してください
- 切替ボタンが不要な場合は `#themeToggle` の `<button>` を削除してください
- `theme-color`（スマホのアドレスバーの色）は切替に追従します

**配色を変えるときの約束（崩すと読みにくくなります）**

- ライム（`--lime`）は、NEON では文字色に使えますが、**PAPER では「黒文字の下に敷く面」専用**です。明るい地の上でライムの文字を置かないでください
- ライムの面に乗せる文字は必ず `--on-lime`、マゼンタの面に乗せる文字は `--on-magenta`（NEON では黒、PAPER では白に切り替わります）
- `--hi` は「大きな強調文字」専用です。本文サイズの文字には使わず、`--fg` / `--fg-dim` を使ってください

## タイムテーブルの書き方

このテンプレートの中心です。書くのは**3つだけ**です。

### ① 外側の `<div class="tt">` の属性

```html
<div class="tt" id="tt"
     data-stages='["MAIN","SUB","LOUNGE"]'
     data-open="11:00"
     data-close="21:00">
```

| 属性 | 必須 | 内容 |
| --- | --- | --- |
| `data-stages` | 任意 | ステージ名。JSON の配列（左から出る順）。`"MAIN, SUB, LOUNGE"` のようなカンマ区切りでも動きます。**属性ごと消すと、中の `data-stage` から自動で拾います**（出てきた順） |
| `data-open` | **必須** | 表の開始時刻 `HH:MM` |
| `data-close` | **必須** | 表の終了時刻 `HH:MM`。開始より前の時刻なら翌日として扱います（例 `data-open="22:00" data-close="04:00"`） |
| `data-date` | 任意 | 開催日 `YYYY-MM-DD`。**今日がこの日のときだけ**「現在」の線が表に入ります。省略すれば線は出ません |

### ② 中に `<div class="act">` を出演のぶんだけ並べる

```html
<div class="act" data-stage="MAIN" data-start="18:30" data-end="19:30"
     data-head data-note="ヘッドライナー">◯◯◯◯◯</div>
```

| 属性 | 必須 | 内容 |
| --- | --- | --- |
| `data-stage` | **必須** | `data-stages` のどれか。一致しない名前のときは、左端のステージに置きます |
| `data-start` | **必須** | 開始時刻 `HH:MM` |
| `data-end` | **必須** | 終了時刻 `HH:MM`。開始より前なら翌日扱い（`23:30` → `01:00` もそのまま書けます） |
| `data-note` | 任意 | 名前の下に小さく添える一言 |
| `data-head` | 任意 | 値のいらない印。付けるとマゼンタの強調枠になります（ヘッドライナー用） |

タグの中身が出演者名です。**並び順は自由**です（JavaScript がステージ順・時刻順に並べ直します）。

### ③ それだけです

- **PC**：時刻（行）× ステージ（列）のグリッドになります。行は5分きざみ、1時間ごとに実線、30分ごとに破線が入ります
- **同じステージで時間が重なる出演**は、自動で左右のレーンに分かれます（転換の被せ、DJ とライブの並行など）。レーンの数だけ、そのステージの列が細く分割されます
- **700px 以下**では、同じ markup のままステージタブ＋縦リストに変わります。表を作り直す必要はありません
- 表の高さは `.tt { --tt-unit: 10px; }`（5分あたりの高さ）、左の時刻欄の幅は `--tt-gut` で調整できます

### 壊れた書き方をしたときの動き

告知サイトは、当日の朝にあわてて書き換えるものです。書き間違えても**ページが真っ白にならない**ように作ってあります。

| 書き間違い | どうなるか |
| --- | --- |
| `data-stages` を消した | 中の `data-stage` からステージ名を自動で拾って、そのままグリッドを作ります |
| `data-stages` の JSON が壊れている | カンマ区切りとして読み直します（`[` `]` `"` は取り除きます） |
| `data-open` / `data-close` が無い・読めない | グリッドをやめて、ステージごとの**素の一覧**に切り替えます（見出し＋時刻＋名前） |
| ある出演の `data-start` / `data-end` が読めない | その出演だけを表の下の「時間未定」にまとめます。表は普通に出ます |
| ある出演が表の時間の外にある | その出演だけを表の下の「時間未定・開催時間外」にまとめます（表が無意味に伸びるのを防ぎます） |
| `data-stage` の名前が `data-stages` に無い | 左端のステージに置きます |

いずれの場合も JavaScript のエラーは出ません。

## カウントダウンの書き方

```html
<div class="cd" id="countdown" data-when="2027-09-18T18:00+09:00" hidden>
```

- `data-when` は **ISO 8601 ＋ 時差**。日本なら末尾の `+09:00` を必ず付けてください
  （付けないと、見る人の端末のタイムゾーンによって残り時間がずれます。時差の無い値は**読みません**）
- 「残り ◯日 ◯時間 ◯分」を表示し、1分ごとに更新します
- **日時を過ぎたら**、マイナスの数字ではなく `ARCHIVE` の表示に変わります（終わったイベントのページをそのまま置いておけます）
- 値が読めないとき（`いつか` / 空 / `2027/09/18 18:00` など）は、**枠ごと静かに消えます**。エラーは出しません
- カウントダウンが不要なら、`<div class="cd">` ごと削除してください

> 配布時の `data-when` は**動作確認用のサンプル値**です。必ず実際の開場日時に差し替えてください。

## Hero の写真

1. `assets/hero.jpg` を置く（横 2000px 程度）
2. `<style>` の `:root` にある次の行のコメントを外す

```css
--hero-photo: url("assets/hero.jpg");
```

写真が無い場合は、ライムとマゼンタのハードなグラデーションだけで成立します（**写真ゼロでも公開できます**）。
写真を使わない構成のままでも、外部画像リクエストは一度も発生しません。

## 特徴

- 1ファイル完結（HTML / CSS / JS すべて込み、外部ライブラリゼロ）。外部画像は `assets/` のキービジュアルのみ
- NEON（暗）／PAPER（明）の2テーマ切替、設定をブラウザに保存、`theme-color` 同期、描画前に適用してちらつきなし
- タイムテーブル：時刻 × ステージのグリッド／重なりの自動レーン分割／スマホのステージタブ／「現在」の線／深夜またぎ対応／壊れた属性からの自動退避
- カウントダウン：時差を明示した1属性だけ。終演後は `ARCHIVE`
- 流れるティッカー（CSSのみ。ホバーと `prefers-reduced-motion` で停止）
- LINE UP：ヘッドライナーだけ2枠ぶんの大きさになるグリッド。写真が無くても面として成立します
- チケット：券種3つ、**SOLD OUT の状態**つき（角のスタンプ・打ち消し線・押せないボタン）
- 注意事項（再入場・年齢制限・撮影・悪天候時）と FAQ（`<details>`、JS が無くても開閉）
- 全56か所の文字色を両テーマで実測。本文はすべて 4.5:1 以上、大きな文字はすべて 3:1 以上
- レスポンシブ（390px で確認済み・横スクロールなし）、コンソールエラーゼロ
- `prefers-reduced-motion` 対応（動きを抑える設定ではティッカーも出現アニメも止まり、すべて表示されます）
- OGP / canonical / theme-color / SVG ファビコン内蔵
- 日本語コメント付きで、HTML に不慣れな方でも差し替えやすい構成

## 掲載内容についてのお願い

告知サイトは、書いたことがそのまま「約束」になります。公開前に必ずご確認ください。

- イベント名・出演者名・会場名・住所・日付・価格・時間は、すべて「◯◯」「△△」「¥◯,◯◯◯」「2027.◯.◯」などのプレースホルダーです。公開前に必ず実際の内容へ差し替えてください
- **実在のアーティスト名・グループ名・ロゴ・アーティスト写真を、許諾なく掲載することはできません。** 出演者の表記（表記ゆれ・並び順・肩書き）は、必ず各事務所／レーベルの指定に従ってください
- 出演が未確定のうちに確定であるかのように書く、決まっていた出演の取消を黙って消す、といった表示は景品表示法・特定商取引法の問題になり得ます。変更・中止はこのページで告知してください
- 動員数・満員御礼・受賞歴・口コミなど、**確認できない数字や評価を書かないでください**（景品表示法／優良誤認）
- **チケットを自分で販売する場合は「特定商取引法に基づく表記」のページが別途必要です**（販売者名・所在地・連絡先・販売価格・支払方法・引渡時期・返品／キャンセルの可否）。フッターにリンク枠を用意しています
- 年齢制限・飲酒の提供・再入場・撮影可否・悪天候時の扱いは、当日のトラブルに直結します。テンプレートの文面をそのまま使わず、自分のイベントの実情に合わせて全部書き換えてください
- 会場名・会場写真・地図の掲載は、会場および地図サービスの利用規約に従ってください
- 他者が権利を持つ写真・フォント・素材を同梱しないでください
