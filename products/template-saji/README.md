# SAJI（匙）— 飲食店のための Web サイトテンプレート v1.0

by IDATSUKA — https://idatsuka.com

食堂・ビストロ・カフェ・パン屋・定食屋 —— 店主がひとりで更新できる、1ファイル完結の
レストラン用 HTML テンプレートです。ビルドツール・フレームワーク・外部ライブラリは一切不要。
`index.html` を編集してアップロードするだけで公開できます。

このテンプレートの中心は **営業時間（`data-hours`）** です。
曜日ごとの営業時間を1か所に書くだけで、「営業中／準備中／本日定休」のバッジ、次の開店時刻、
店舗案内の営業時間表、定休日の表示が、すべて自動で揃います。
時間を変えたときに直す場所は、いつでもその1か所だけです。

写真がまだ1枚も無くても成立するように、料理写真の枠には暖色のグラデーションが入っています。

## 使い方

1. `index.html` をテキストエディタで開く
2. ファイル冒頭のコメントに従い、`EDIT:` と書かれた箇所を自分の店の内容に差し替える
3. **営業時間は `data-hours` の1か所だけ**書き換える（下の「営業時間の設定方法」を参照）
4. 写真を `assets/` に置く（`hero.jpg` / `dish-1.jpg` / `dish-2.jpg` / `dish-3.jpg`）
5. `<style>` 内の `:root` のCSS変数で配色を調整する（夜テーマは `[data-theme="night"]` ブロック）
6. サーバー（GitHub Pages / Netlify / レンタルサーバー等）に `index.html` と `assets/` をアップロード

### 最初に差し替える6か所

| 場所 | 内容 |
| --- | --- |
| `<title>` / `description` / `og:` / `canonical` | 店名・業種・地域・公開URL |
| HERO の `data-hours='{...}'` | 曜日ごとの営業時間（バッジ・営業時間表・定休日がここから自動で入ります） |
| HERO の `<h1 class="hero-name">` と `.hero-lead` | 店名と、一行の紹介 |
| 品書きの `<li class="m-item">` | 品名・説明・価格（点線は自動で引かれます） |
| 店舗案内の `<table class="info-table">` | 住所・電話・席数・支払い方法 |
| 電話番号（3か所） | HERO のボタン／ご予約の `tel:` リンク／フッター。表示用の番号と `tel:` の数字の両方 |

### テーマについて

- ナビ右上の「昼／夜」で、昼（`day`）と夜（`night`）の2テーマを切り替えられます（選択はブラウザに保存されます）
- 最初から夜で表示したい場合は `<html lang="ja" data-theme="day">` を `data-theme="night"` に変更してください
- 切替ボタンが不要な場合は `#themeToggle` の `<button>` を削除してください
- `theme-color`（スマホのアドレスバーの色）は切替に追従します
- 配色は `:root`（昼）と `[data-theme="night"]`（夜）のCSS変数だけで決まります。色を変えるときは、
  必ずこの2か所を両方直してください

| 変数 | 役割 |
| --- | --- |
| `--bg` / `--bg2` | 地の色／一段沈めた面（ご予約の帯・地図枠など） |
| `--fg` / `--fg-dim` / `--muted` | 本文／補助文／ラベル・飾りの小さな文字 |
| `--accent` | 深緑。罫・見出しの印・営業中バッジ・ご予約ボタン |
| `--brass` / `--brass-ink` | 真鍮。装飾用／価格などの小さな文字用（昼は読みやすいよう少し濃い色） |
| `--photo-warm` / `--photo-mid` / `--photo-deep` | 写真が入るまでの枠のグラデーション |

### 写真について

- `assets/` に `hero.jpg`（縦長・1600×2000 程度）、`dish-1.jpg`〜`dish-3.jpg`（4:3・1200×900 程度）を置きます
- **ファイルが無いあいだは、暖色のグラデーションと皿の輪郭が表示されます**（画像切れのアイコンは出ません）。
  写真を置くと、枠の中の目印（`assets/hero.jpg` の文字・皿・匙）は自動で消えます
- 写真は1枚 300KB 程度までを目安に圧縮してください
- 写真・イラスト・フォントは、ご自身が権利を持つ（または利用許諾を得た）ものだけをお使いください

## 特徴

- 1ファイル完結（HTML / CSS / JS すべて込み、外部ライブラリゼロ。外部画像は `assets/` の写真のみ）
- 昼／夜の2テーマ切替、設定をブラウザに保存、`theme-color` 同期
- **営業中バッジ**：`data-hours` ひとつから「営業中／準備中／本日定休」と次の開店時刻を自動表示。
  中休みのある二部営業・深夜営業（翌1:00まで）・定休日に対応し、1分ごとに更新されます
- **リーダー罫つきの品書き**：品名と価格のあいだを点線がつなぎ、価格は右端で揃います。
  長い品名は品名だけが折り返し、価格は折り返しません（点線は最後の行のベースラインに揃います）
- 営業時間表は `data-hours` から自動生成。今日の行に印が付きます
- 縦書きの添え書き（900px 以下では自動で横書きに切り替わります）
- 地図プレースホルダー／お知らせ／電話・オンライン予約の導線
- レスポンシブ（390px で確認済み・横スクロールなし）
- `prefers-reduced-motion` 対応（動きを抑える設定のユーザーにはフェードも止まり、すべて表示されます）
- OGP / canonical / theme-color / SVG ファビコン内蔵
- 日本語コメント付きで、HTML に不慣れな方でも差し替えやすい構成

## 営業時間（data-hours）の設定方法

HERO にある、この1か所だけを書き換えます。

```html
<div class="hours" id="hours"
     data-hours='{"mon":[["11:30","14:00"],["17:30","21:00"]],
                  "tue":null,
                  "wed":[["11:30","14:00"],["17:30","21:00"]],
                  "thu":[["11:30","14:00"],["17:30","21:00"]],
                  "fri":[["11:30","14:00"],["17:30","22:00"]],
                  "sat":[["11:30","15:00"],["17:30","22:00"]],
                  "sun":[["11:30","15:00"]]}'>
```

### 書式

- 曜日のキーは `mon` `tue` `wed` `thu` `fri` `sat` `sun`（小文字3文字）
- 値は **営業する日 → `[["開始","終了"], ...]`**、**定休日 → `null`**
- 時刻は `"HH:MM"` の24時間表記（`"9:00"` のように1桁でも構いません）
- 中休みがある日は、枠を2つ並べます … `[["11:30","14:00"],["17:30","21:00"]]`
- 通し営業の日は、枠1つで構いません … `[["11:00","22:00"]]`
- **深夜営業**は「終了 < 開始」と書けば翌日扱いになります … `[["18:00","01:00"]]` → 表示は「18:00 – 翌1:00」
- 属性全体は **シングルクォート `'` で囲み、中の文字列は JSON のダブルクォート `"`** で書きます（逆にしないでください）
- 途中に改行を入れても構いません（上の例のように、曜日ごとに改行すると読みやすくなります）

### この1か所から自動で入るもの

| 場所 | 表示 |
| --- | --- |
| HERO のバッジ | `営業中` / `準備中` / `本日定休` |
| バッジの右側 | 営業中なら「21:00 まで」、それ以外は「本日 17:30 から」「明日 11:30 から」「金曜 11:30 から」 |
| 店舗案内「営業時間」 | 月曜〜日曜の表（定休日の曜日は「定休日」と表示。今日の行には印と `TODAY`） |
| 店舗案内「定休日」 | `null` にした曜日を「火曜・水曜」のように並べます（全曜日に営業時間があれば「無休」） |

### 判定のルール

- **営業中** … いまの時刻がどれかの枠の中（開始時刻ちょうどは営業中、終了時刻ちょうどは営業終了）。
  前日から日をまたいで営業している場合も営業中になります
- **準備中** … 今日は営業日だが、いまは枠の外。次の開店（今日の夜／翌営業日）を表示します
- **本日定休** … 今日が `null`。次に開く曜日と時刻を表示します
- 次の開店は7日先まで探します。「本日」「明日」、それ以降は「金曜」のように曜日で表示します
- バッジは1分ごとに見直されるので、開店時刻をまたいでも表示が古いままになりません

### 書き間違えたときの動作（重要）

**ページは壊れません。** 次のように、静かに元の表示に戻ります。

| 状況 | 動作 |
| --- | --- |
| `data-hours` 属性が無い | バッジは表示されず、営業時間表は「営業時間はお電話でお問い合わせください」のまま |
| JSON が壊れている（カンマの打ち間違いなど） | 同上（バッジは出ません） |
| ある曜日の値が配列でない（例: `"11:30-14:00"`） | その曜日は定休日として扱われます |
| 時刻の書式が違う（例: `"25時"`） | **その枠だけ**無視され、同じ日の正しい枠は表示されます |
| すべての曜日が `null` | バッジは「本日定休」、定休日はすべての曜日になります |

バッジが出ないときは、`data-hours` のどこかで JSON が壊れています。
カンマ・カギ括弧・クォートの対応を確認してください。

### 祝日・臨時休業について

祝日や臨時休業は、自動では判定されません（祝日の扱いは店ごとに違うためです）。
「お知らせ」に1件足すか、「定休日」の行に一言添えてください。

## 品書きの書き方

1品は `<li class="m-item">` 1つです。**点線は CSS が自動で引く**ので、品名と価格の間には何も書きません。

```html
<li class="m-item">
  <p class="m-row"><span class="m-name">◯◯のテリーヌ</span><b class="m-price">¥◯,◯◯◯</b></p>
  <p class="m-desc">△△を重ねて、ゆっくり火を入れました。</p>
</li>
```

- 説明が不要なら `<p class="m-desc">` の行ごと削除してください
- 品名の後ろに小さな注記を付けるときは `<span class="m-tag">昼のみ</span>` を品名の中に入れます
- 価格は `¥2,000` でも `¥2,000〜` でも `時価` でも構いません。長い品名でも折り返さず右端に残ります
- 分類（前菜・主菜…）は `<div class="m-cat">` 単位です。PCでの左右2列は HTML の
  2つの `<div>` で分かれているので、列の高さを揃えたいときは分類をこの2つの `<div>` のあいだで
  移動させてください（スマホでは自動で1列になります）
- **価格は税込の総額表示が必要です**（総額表示義務）。「※ 表示は税込価格です」の行は消さずに、
  サービス料・席料の有無に合わせて書き換えてください
