Motion · One page · One pulse

画面が、脈打つ。 動く1枚の ランディングページ。

PULSE はヒーロー動画とキネティックタイポで視線を掴む動的 LP テンプレート。ビルド不要の1ファイル。ダーク / ライト、reduced-motion 対応。

Features

01

ループするヒーロー

無音・自動再生の webm + mp4。ポスター同梱。動きを減らす設定では静止画にフォールバック。

02

キネティックタイポ

CSS only の見出し入場。シアン×マゼンタのグラデーションで NULLC トーンに寄せた視線誘導。

03

微動する UI

ショーケースの疑似ブラウザがゆるく浮かぶ。差し替え前提の Spec フレーム付き。

How it works

STEP 01

コピーと動画を差し替える

EDIT コメントと media/ の差し替え手順に従い、見出し・CTA・ヒーロー素材を自分のオファーに合わせる。

STEP 02

色を2つ決める

--cyan と --magenta を変えれば全体のトーンが揃う。ダーク / ライト両対応。

STEP 03

アップロードして公開

GitHub Pages / Netlify / レンタルサーバーへ index.html と media/ を置くだけ。

FAQ

コーディング知識は必要ですか？

テキスト編集ができれば十分です。EDIT コメントと CSS 変数、media/ の差し替えだけで見た目と文言を変えられます。

ZEN / RAY との違いは？

ZEN はポートフォリオ、RAY は1オファーの静的寄り LP。PULSE はヒーロー動画とキネティック表現で「動き」を前面に出した動的 LP です。

動画は必ず必要ですか？

推奨ですが必須ではありません。media を外し、CSS のグロー背景だけでも成立します。reduced-motion 利用者にはポスター静止画が表示されます。

実績数字やクライアント名を載せてもいいですか？

検証できるもの・公開許可があるものだけにしてください。想定案件は Spec / Concept / Personal と明示し、捏造は避けてください。
