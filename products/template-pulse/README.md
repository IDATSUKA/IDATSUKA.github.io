# PULSE — Dynamic Landing Page Template v1.0

by IDATSUKA — https://idatsuka.com

Sister to **ZEN** (portfolio) and **RAY** (minimal LP). **PULSE** is a motion-first single-page landing template: looping hero video, kinetic type, and a subtly animated UI showcase.

One HTML file + `media/`. No build tools. Dark / Light themes. Japanese comments. `prefers-reduced-motion` safe.

## Quick start

1. Open `index.html`
2. Replace every `EDIT:` block (copy, links, placeholders)
3. Tune `--cyan` / `--magenta` in CSS variables
4. Swap `media/hero-loop.webm`, `media/hero-loop.mp4`, and `media/hero-poster.jpg` (same framing recommended)
5. Upload `index.html` + `media/` to GitHub Pages / Netlify / any static host

## Sections

Nav → Hero (video) → Features×3 → Showcase → How it works → Pricing teaser → FAQ → Final CTA → Footer

## Hero video notes

- `playsinline` `autoplay` `muted` `loop` `preload=metadata` + `poster`
- Sources: webm then mp4
- Under `prefers-reduced-motion: reduce`, video is paused/hidden and the poster is shown
