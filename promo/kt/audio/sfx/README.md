# 効果音（効果音ラボ）

ここに次の名前でファイルを置いてください（wav / mp3 / ogg どれでも可）。置き場所と時刻は `../cues.json` が決めています。

| ファイル名 | 鳴らす時刻 | 探し方（効果音ラボ） | 用途 |
|---|---|---|---|
| `shimmer` | 0.06秒 | キラッ / 光る（短く上品なもの） | 冒頭の細線 |
| `whoosh` | 3.08秒・11.08秒 | シュッ / 風を切る | 白→黒のスラッシュワイプ |
| `tick` | 4.67秒・6.00秒・7.33秒 | カーソル移動 / 小さな決定音 | 01・02・03 の切り替え |
| `swish` | 8.67秒 | スワイプ / 紙をめくる（軽いもの） | スマホがせり上がる |
| `hit` | 13.33秒 | 余韻のある低い単音 / ピアノ・鐘の一打 | エンドカード |

上品に仕上げるコツ：派手な「ドーン」「キュイーン」系は避け、短く・小さく・高域が強すぎないものを選ぶ。音量は `cues.json` の `gain_db` で調整。
使う前に効果音ラボの利用規約を確認してください。
