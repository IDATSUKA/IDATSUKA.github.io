# 投稿用の短いクリップ

`promo/ads` の静止画は「何があるか」を伝えます。**伝えられないのは、この製品が
実際には何でできているか** — 風に揺れる布、順に点っていく灯り、サイト全体が夜から
紙に変わる瞬間。これは動画でしか残りません。そしてタイムラインで伸びるのは動画です。

作り直し: `node tools/promo-clips.js`（準備は `tools/og-cards.md` と同じ2つのローカルサーバー）

| ファイル | 長さ | 容量 | 中身 |
| --- | --- | --- | --- |
| `x-theme.mp4` | 19.0s | 1.4MB | サイト全体が暗→明→暗に切り替わる |
| `x-scenes.mp4` | 17.8s | 3.8MB | トップ背景の5シーン（Ring / Flow / Plexus / Aurora / Lattice） |
| `x-veil.mp4` | 12.0s | 1.7MB | VEIL の灯り、cinema↔studio、事例の帯まで |
| `x-noren.mp4` | 14.7s | 0.8MB | NOREN の暖簾と、その下の年表 |

1280×720 / H.264 / 音声なし。X・LinkedIn・Slack にそのまま上げられます。

## 投稿文の案

**書いていないこと**を確認してから出してください。数字、実績、「話題の」「人気の」は
根拠がないなら書かない（→ `DESIGN.md` 10章）。

> サイト全体に明るい配色を足しました。
> 色は全部トークン経由なので、片方だけ壊れることがありません。
> 発光は明側では切っています。白地では光にならず、にじみになるので。
> https://idatsuka.com

> トップの背景は5種類あって、日替わりで変わります。

> https://idatsuka.com

> 同じ1枚の夜景が、夜テーマと昼テーマで別の表情になります。
> 1ファイル完結・日本語コメント付き・商用利用可。

### `x-noren.mp4`

## 気をつけること

- **`x-noren.mp4` の動きは意図的に控えめです。** 常時揺らすと嘘くさくなるので、
  風は8〜20秒に一度しか通りません。クリップの前半で一度吹きます。
  「派手に動く素材」が要る場面には向きません。
- 1投稿につき1本。4本まとめて貼ると、どれも見られません。
- リンクを本文に入れると表示が落ちる、という話がありますが、**計測が入るまでは
  仮説のままです。** `js/analytics.js` にトークンが入ってから、貼り方を変えて比べてください。
